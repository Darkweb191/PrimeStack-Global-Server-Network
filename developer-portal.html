Authentication

Every API request must be signed with HMAC-SHA256.

const crypto = require('crypto');
function signRequest(keyId, secret, body) {
  const ts = Date.now().toString();
  const data = keyId + ts + (body ? JSON.stringify(body) : '');
  return crypto.createHmac('sha256', secret).update(data).digest('hex');
}

Legal Procedures

PrimeStack does NOT hold your funds. We are a switch and routing engine. Funds pass through and are immediately withdrawable.
Mandatory 30% Platform Fee
Auto-deducted on every transaction. Non-negotiable. Cannot be reversed.
No Withdrawal Restrictions
