Receive Funds from Any External Terminal

Any terminal from any country (South Africa, UAE, UK, anywhere) can send funds to your terminal. The external terminal does NOT need to be registered on PrimeStack first — it is auto-created on the first transfer.

How External T2T Works
1
Customer sends T2T request
The customer's server calls your API with their terminal ID, amount, and your terminal ID as destination
2
HMAC authentication
The request is verified using HMAC-SHA256 signature with the key ID and secret you provided
3
External terminal auto-created
If the sender's terminal ID doesn't exist in PrimeStack, it's automatically registered as an external terminal
4
Ledger entry posted
Funds debited from sender terminal account, credited to your terminal account (PST-001-PRIME)
5
Transfer completed
Both terminals receive updated balances. Reference and journal entry returned for reconciliation.
What the Customer (Sender) Needs to Provide

The customer sends a POST request to your server with these fields:

type"T2T" required
amount"1000.00" required
currency"USD" required
sourceType"TERMINAL" required
sourceId"SA-TERM-001" required — their own terminal ID (any name)
destType"TERMINAL" required
destId"PST-001-PRIME" required — YOUR terminal ID
description"Payment for services" optional
Key point: The customer uses their OWN terminal ID as sourceId (e.g., "SA-TERM-001" for a South Africa terminal). It does not need to be pre-registered. Your terminal "PST-001-PRIME" is the destination.

Complete Code — Customer Sends T2T Transfer
// The customer runs this on their server (e.g., in South Africa)
const crypto = require('crypto');

// You provided these to the customer:
const SERVER  = 'https://primestack-global-server-network.onrender.com';
const KEY_ID  = 'psk_demo_key_001';
const SECRET  = 'YOUR_HMAC_SECRET';  // you gave them this

// The transfer request body:
const body = {
  type:        'T2T',
  amount:      '1000.00',
  currency:    'USD',
  sourceType:  'TERMINAL',
  sourceId:    'SA-TERM-001',      // their terminal ID (auto-created)
  destType:    'TERMINAL',
  destId:      'PST-001-PRIME',     // YOUR terminal ID
  description: 'Payment from South Africa customer',
};

// Sign with HMAC:
const bodyStr = JSON.stringify(body);
const ts = Date.now().toString();
const sig = crypto.createHmac('sha256', SECRET)
                    .update(KEY_ID + ts + bodyStr).digest('hex');

// Send the request:
const res = await fetch(SERVER + '/transfers', {
  method: 'POST',
  headers: {
    'Content-Type': 'application/json',
    'x-primestack-key-id': KEY_ID,
    'x-primestack-timestamp': ts,
    'x-primestack-signature': sig,
  },
  body: bodyStr,
});

const result = await res.json();
console.log('Reference:', result.data.reference);
console.log('Status:', result.data.status);  // "COMPLETED"
