Terminal-to-Terminal (T2T) Transfers

T2T transfers move funds between two terminals on the PrimeStack network. The sender initiates the transfer from their terminal, and the receiver's terminal is credited via an immutable double-entry ledger entry.

How T2T Works — Complete Flow
1
Sender registers a connection
The sender creates an S2S connection on our platform with their server URL, API secret, and IP address. This generates a Connection ID.
2
Receiver whitelists sender IP
The receiver (you) adds the sender's server IP to the connection's allowedIps list. Only whitelisted IPs can push funds.
3
Sender pings to verify
The sender calls POST /s2s/connections/:id/ping to verify connectivity. This sends a signed health request to the receiver's server.
4
Sender initiates T2T transfer
Sender calls POST /transfers with type: "T2T", specifying source terminal, destination terminal (PST-001-PRIME), amount, and currency.
5
Ledger posts the entry
The ledger engine debits the source terminal account and credits the destination terminal account in a single atomic transaction.
6
30% admin fee auto-split
30% of the transfer amount goes to the platform admin wallet. 70% goes to the merchant wallet. This is mandatory and automatic.
7
Transfer completed
Both terminals receive the updated balance. The transfer reference and journal entry reference are returned for reconciliation.

IP Whitelisting — How It Works

IP whitelisting is mandatory. Only IPs in the connection's allowedIps list can push funds. All other IPs receive a 403 Forbidden.

When creating or updating a connection, include the sender's server IPs:

The ping sends a signed GET request to the connection's endpointUrl/health.

It verifies: (1) the server is online, (2) the API secret is valid, (3) the HMAC signature matches, (4) network latency is acceptable.

Complete T2T Transfer Code Example

Full Node.js code for the sender to initiate a T2T transfer:

// ── 1. Sign the request with HMAC ──
const crypto = require('crypto');

const KEY_ID  = 'psk_demo_key_001';       // receiver provides this
const SECRET  = 'YOUR_HMAC_SECRET';       // receiver provides this (private)
const SERVER = 'https://primestack-global-server-network.onrender.com';

// ── 2. Build the T2T transfer body ──
const body = {
  type:        'T2T',              // Terminal-to-Terminal
  amount:      '1000.00',          // amount to transfer
  currency:    'USD',              // 3-letter currency code
  sourceType:  'TERMINAL',          // source entity type
  sourceId:    'PST-002-PRIME',     // sender's terminal TID
  destType:    'TERMINAL',          // destination entity type
  destId:      'PST-001-PRIME',     // receiver's terminal TID
  description: 'Payment for invoice INV-2026-001',
};

// ── 3. Compute HMAC signature ──
const bodyStr = JSON.stringify(body);
const ts      = Date.now().toString();
const data    = KEY_ID + ts + bodyStr;
const sig     = crypto.createHmac('sha256', SECRET).update(data).digest('hex');

// ── 4. Send the transfer ──
const res = await fetch(SERVER + '/transfers', {
  method:  'POST',
  headers: {
    'Content-Type':            'application/json',
    'x-primestack-key-id':     KEY_ID,
    'x-primestack-timestamp':  ts,
    'x-primestack-signature':   sig,
  },
  body: bodyStr,
});

const result = await res.json();
console.log('Transfer:', result.data.reference);
console.log('Status:', result.data.status);      // "COMPLETED"
console.log('Journal:', result.data.journalEntryRef);

Legal Procedures

No Custody
PrimeStack does NOT hold your funds. We are a switch and routing engine. Funds pass through and are immediately withdrawable.
Mandatory 30% Platform Fee
Auto-deducted on every transaction. Non-negotiable. Cannot be reversed. Applied at the ledger level before funds reach your wallet.
No Withdrawal Restrictions
Withdraw your 70% share anytime. No admin approval needed. The 30% fee is already deducted at the transaction level.
KYC / Compliance
Merchants must complete KYC. Bank details encrypted AES-256-GCM. Immutable audit trail on every transaction.
AML / Fraud Monitoring
All transactions screened by fraud engine (velocity, blacklist, AML). Suspicious activity may be temporarily held pending review.
Data Protection
AES-256-GCM at rest. HMAC-SHA256 auth. Nonce replay protection. IP allowlisting. SSRF protection.
