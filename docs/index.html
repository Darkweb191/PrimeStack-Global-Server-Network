Security

Bank-Grade Security.
Every Layer.

Zero trust architecture. Every byte encrypted, every request signed, every nonce tracked.

🔐

AES-256-GCM Encryption

API secrets, bank credentials, and sensitive data encrypted at rest with AES-256-GCM. Random 12-byte IV per write. GCM authentication tag detects any tampering before decryption proceeds.

✍️

HMAC-SHA256 Authentication

Every API call signed with HMAC-SHA256 over the canonical payload: keyId + timestamp + body. 5-minute timestamp drift window. Constant-time comparison with timingSafeEqual prevents timing attacks.

🛡️

Nonce Replay Protection

Every inbound S2S payment requires a unique nonce. Stored in Redis with a 10-minute TTL (SET NX — atomic) and persisted to PostgreSQL for audit. Duplicate requests rejected with 401 REPLAY_DETECTED.

🚧

IP Allowlist + SSRF Shield

Per-connection IP allowlists enforced at route level before any processing. Callback URL validation blocks private IP ranges (RFC-1918), localhost, loopback, link-local, and cloud metadata endpoints (169.254.169.254).

hmac-sign.js — Sign any API request 
const crypto = require('crypto');

function signRequest(keyId, secret, body) {
  const timestamp = Date.now().toString();
  const data = keyId + timestamp + (body ? JSON.stringify(body) : '');
  const sig = crypto
    .createHmac('sha256', secret)
    .update(data)
    .digest('hex');
  return {
    'x-primestack-key-id':    keyId,
    'x-primestack-timestamp': timestamp,
    'x-primestack-signature': sig,
  };
}
